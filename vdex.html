首页VtoyVDEX设置

VDEX.HTML

把你的 HTML、CSS、JS 放到 VDEX，得到一个 vdex.html?name=名称 的网站。名称必须是小写字母、数字和 -，不能使用下划线。

🌐

选择套餐

标准版 = 纯静态托管；专业版 = 支持登录 + 游戏数据；企业版 = 完整 VTX 调用（登录跳转 API_LOGIN，付款/收款跳转 API_VTXPAY）。

版本容量价格能力操作
打开站点

名称注册后不能修改；标准版不需要登录能力，专业版支持登录与游戏数据，企业版支持完整 VTX 调用。购买后 30 天内有效。

站点内容

内容会存到 KV，公开地址为 vdex.html?name=名称。容量按套餐限制。

远程 SSH 服务器

地址— 端口— 用户名— 密码— 状态—
可用于 Code / VS Code Remote SSH 等客户端；凭据会长期保存在「我的站点」中。
