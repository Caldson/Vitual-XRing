VitualGit 是一个 GitHub 风格的开源仓库浏览器。输入公开仓库地址，查看文件与 README；国内访问通过 GitHub Proxy 镜像。

⌕
仓库浏览查看公开 GitHub 仓库的描述、语言、Star、文件列表和 README。
Proxy 镜像通过 gh-proxy.com 镜像打开 GitHub 页面和原始文件，改善国内访问速度。
Vitual XRing 账户使用 Vitual XRing 登录，不需要 GitHub 密码。
