Vtoy 小程序

Vtoy 不再在网站里编辑代码。安装 VS Code 扩展后，登录 VTX 账户，用 Vtoy VDEX 文件夹准备、缓存和推送应用。

Vtoy / VDEX VS Code 扩展

在 VS Code 左侧活动栏打开 Vtoy / VDEX，登录后点「准备Git文件夹」，在本地编辑 HTML / CSS / JS，再推送更新。

下载 VSIX 扩展
1. 下载并安装VS Code → 扩展 → ... → Install from VSIX。
2. 登录 VTX左侧 Vtoy / VDEX 图标，登录账户。
3. 准备并推送准备Git文件夹，编辑后再推送更新。

公开应用地址仍然是 vtoy.html?app=名称。网站不提供在线编辑。
